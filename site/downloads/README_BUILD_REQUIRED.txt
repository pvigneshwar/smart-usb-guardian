CLIENT BUILD REQUIRED

Run the GitHub Actions workflow named:
Build Smart USB Guardian clients

The workflow creates:
- Open Secure USB.exe
- USBGuardian.exe (compatibility copy)
- USBMonitor.exe
- USBGuardianMobile.apk
- Smart_USB_Guardian_One_Click_Setup.zip
- Smart_USB_Guardian_Windows_Client.zip

The final pendrive root should contain only:
- Open Secure USB.exe
- usb_guardian.id
- secure_data.hc
