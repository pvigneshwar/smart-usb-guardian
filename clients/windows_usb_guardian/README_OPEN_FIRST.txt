SMART USB GUARDIAN - VAULT-ONLY USB APP

Final pendrive root:
- Open Secure USB.exe
- usb_guardian.id
- secure_data.hc

1. Register the pendrive in the owner dashboard.
2. Download the generated usb_guardian.id.
3. Create a VeraCrypt container named secure_data.hc.
4. Keep every private file inside secure_data.hc.
5. Build Open Secure USB.exe using build_exe.bat.
6. Copy the three required files to the pendrive root.

When Open Secure USB.exe is opened manually, the owner dashboard records an APPLICATION OPENED activation event. When USBMonitor.exe is installed on a Windows computer, insertion is detected and the application launches automatically.
